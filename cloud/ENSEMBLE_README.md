# LABEQ · لبِق

Research configuration with the original interface and Maha artwork. Original Faisal performs communication-style routing. Qwen3.5-4B with the preserved Saudi pilot and completed v2 adapters generates four candidate messages. A pinned Qwen3.6 CPU model supplies advisory meaning plans, selects among actual candidates or rejects them all, and performs source-grounded review. This is a combined inference system, not evidence that either adapter independently generalizes.

This configuration must pass its recorded runtime and held-out gates before public selection. Individual training failures remain documented in GitHub. No hand-written scenario response or browser-voice substitute is used. Model-produced text still requires review.

Faisal is Omer Nacar's Jev-inspired Arabic decision model under CC BY-NC 4.0. This is an attributed noncommercial research demonstration. The Qwen models and public GGUF follow their upstream Apache-2.0 terms. Private response weights remain in their authorized private repositories.

Project source, model evidence and original team credits: https://github.com/LeenAlaslani/Labeq.
