# LABEQ V16 — Human evaluation set (no results claimed)

For each case, run auto-style, then one alternate style if appropriate. A response passes only if the actual user goal survives the rewrite, nothing is invented, the wording sounds natural to a Saudi speaker, and a person would plausibly send it. Rate each dimension from 1 to 5 and keep real failures as regression tests.

| # | Relationship | Situation | User goal | Failure to watch for |
|---|---|---|---|---|
| 1 | Work colleague | A colleague repeatedly delegates their work | Set a lasting boundary without harming rapport | "I can't today" instead of "I can't keep doing this" |
| 2 | Friend | A misunderstanding led to tension | Reopen the conversation calmly | Inventing that the user shouted or lied |
| 3 | Friend | The user explicitly forgot an important commitment | Apologize and take responsibility | Deflecting or blaming the friend |
| 4 | Manager | New task conflicts with an earlier deadline | Ask to clarify priorities | Refusing work outright or inventing a timeline |
| 5 | Customer | A promised item has not been delivered; status is unknown | Communicate uncertainty professionally | Claiming the package shipped or offering a made-up date |
| 6 | Family | A relative keeps asking intrusive personal questions | Set a respectful privacy boundary | Insulting the relative or giving unnecessary details |
| 7 | Friend | A friend sent an ambiguous text | Ask what they intended | Acting as if the friend is angry without evidence |
| 8 | Work colleague | Team member took credit for shared work | Address attribution respectfully | Accusing them of deliberate theft without evidence |
| 9 | Customer | User made a mistake in an order | Own the mistake and propose next steps | False excuses or pretending problem is resolved |
| 10 | Friend | The user wants to decline an invitation | Decline kindly without fake promises | "Maybe next week" when no next-week plan exists |
| 11 | Manager | User wants feedback after a rejection | Ask for specific improvement areas | Begging, blame, or excessive self-criticism |
| 12 | Neighbor | Unexpected loud noise happened once; origin unclear | Ask politely about the noise | Threats or declaring the neighbor guilty |
| 13 | Work | User wants to request a salary review | Ask for a meeting with evidence | Inventing performance metrics or salary figures |
| 14 | Family | Two family members disagree about plans | Express a preference while preserving respect | Choosing sides, insulting, or ignoring the user's preference |
| 15 | Friend | User wants to compliment a friend's achievement | Be warm and specific without exaggeration | Turning congratulations into rejection or apology |

**Quality questions:** Does it address the actual issue? Preserve the intent? Respect the relationship? Use natural Saudi Arabic without unnecessary classical phrasing? Avoid invented facts or promises? Would you send it as written? Does changing to a different style make a meaningful difference without changing the goal?

**Important:** A good result in one case says nothing about overall model reliability. Share aggregate scores only after independently testing and recording them.
